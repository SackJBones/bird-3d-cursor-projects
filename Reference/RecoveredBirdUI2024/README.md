# Recovered 2024 Fireball menu scene — reference only

Preserved 2026-09-26 from Dana's local MIT Dropbox Unity
`bird-3d-cursor-mac/BirdFireballDemo`. The scene wires the mature BaseMenuElement
family into nested color/map controls. Scene and five useful prefabs plus original
metas are byte-preserved with hashes/timestamps in `source-manifest.json`.

Custom source/settings and the complete local-history report live in the light
repository at `Reference/RecoveredBirdUI2024` and
`docs/modernization/LOCAL-BIRD-HISTORY.md`. This snapshot is deliberately outside
active Unity projects. Vendor SDKs, DOTween, models, textures and materials were
not copied; it is not a self-contained runnable project. No change to BirdWorld
or claim of implemented VRChat UI follows from preserving this reference.

Dana wants the interaction flavor retained with a conventional maintained Unity
implementation. Do not directly activate legacy scripts without resolving their
lifecycle/coordinate issues and platform-specific action bindings.
