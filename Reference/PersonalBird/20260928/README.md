The existing coastal world now contains a reusable, local per-visitor Bird
station at its arrival pedestal. Touch the cyan light or use normal VRChat
Interact; both hands work automatically with the unchanged Lab 14 pipeline.
Use again puts Bird away. This is not a portable Item or network-visible cursor.

The checked sources live in the light repository, including PERSONAL-BIRD.md,
BIRD-PORTABILITY.md and the detailed dated CHECKPOINT. Both platform check files
and normal SDK build records are retained here. Android/Windows image directories
contain synthetic compiled-Udon cursor/trail raster checks at 1 m, 4 m, 30 m and
10 km, including a separate all-black occlusion assertion. These are not headset
feel or performance measurements. Pedestal.png is an actual Unity scene render.

issue: unobstructed light, legible nearby instructions, fitting the quiet arrival.

scores for the unchanged architecture. Physical reach/readability acceptance is
separate.
